# RecruitIQ

> AI-powered recruitment intelligence for modern hiring teams.

RecruitIQ is an AI-powered recruitment platform that helps recruiters screen, analyze, and rank candidates faster using Large Language Models (LLMs) and Retrieval-Augmented Generation (RAG).

Instead of manually reviewing hundreds of resumes, recruiters can upload resumes and job descriptions, receive AI-powered candidate rankings, generate interview questions, and search candidates using natural language.

## 🚀 Features (MVP)

- 🔐 Secure Authentication
- 📄 Resume Upload & Parsing
- 💼 Job Description Analysis
- 🤖 AI Candidate Matching
- 📊 Recruiter Dashboard
- 🔍 Semantic Candidate Search (RAG)
- 💬 AI Recruitment Assistant
- 🎯 AI-Generated Interview Questions
